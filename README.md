Project idea :

This project focuses on building a practical web application that simulates a real-world gold tracking platform, where users can view live gold prices and manage their own gold assets.

The application will rely on real API data to calculate different gold values (gram, karat, coins, and bars), convert currencies, and provide insights into user-owned assets such as profit and loss.
